
# 運用
inboxフォルダを定期的にチェックし、必要に応じて整理する。整理方法として、以下の2つを適用する。
- researchフォルダ内の内容は時がたつにつれて古くなることがあるため、inboxフォルダ内の内容と既存のresearchフォルダ内の内容を比較し、researchフォルダ内の内容が古くなっている場合は、inboxフォルダの情報を上書きして情報を更新する。
- obsidianを利用しているので、タグをうまく活用することによって、情報の検索性を高め、必要な情報を迅速に見つけ出せるようにする。

# 運用する上での検討事項
synthesisに情報を格納する際は、他のフォルダとどう使い分けるか、また各フォルダどれくらいの粒度の情報を格納すべきか。
