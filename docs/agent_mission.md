# Antigravity Agent用 深掘り調査ミッション

このプロンプトをAntigravityのAgent Side Panel（エージェントマネージャー）に貼り付けることで、特定のトピックについてブラウザを活用した詳細な調査を実行させることができます。

---

## ミッション定義：特定論文の深掘り調査とObsidian整理

### コンテキスト
私は「Research/Inbox/」フォルダに自動収集された論文リストを持っています。
これから指定するキーワードや特定の論文について、ブラウザを使って詳細を調査し、私のObsidian Vaultに最適な形式で保存してください。

### 指示
1. **検索と抽出**:
   Google ScholarまたはSemantic Scholarで「{{キーワードまたは論文名}}」に関する最新情報を探してください。
   単なるAbstractだけでなく、以下の情報を可能な限り抽出してください。
   - 提案手法の独自性（Contribution）
   - 実験環境やデータセットの詳細
   - 未解決の課題（Future Work）
   - 実装（GitHubリポジトリ）の有無

2. **Obsidianへの保存**:
   「/Research/Inbox/」配下に、既存のテンプレートに従ってMarkdownファイルを生成（または更新）してください。
   ファイル名は「YYYY_タイトル（短縮）.md」としてください。

3. **ナレッジの紐付け**:
   「技術知見DB/」フォルダにある既存のメモを参考に、それらと関連がある場合は「Related Notes」セクションを作成してリンクを貼ってください。

### 制約事項
- 重複するファイルを作成しないでください。
- 日本語と英語の両方のリソースを対象にしてください。
- 重要な図解がある場合は、その内容を言葉で説明するか、URLを記録してください。
