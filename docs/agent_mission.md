# Antigravity Agent用 深掘り調査ミッション

このプロンプトをAntigravityのAgent Side Panel（エージェントマネージャー）に貼り付けることで、特定のトピックについてブラウザを活用した詳細な調査を実行させることができます。

---

## ミッション定義：調査・統合と知識の昇華

### コンテキスト
私は `knowledge/` フォルダを起点とした知識管理システムを運用しています。
`knowledge/inbox/` には論文や市場動向（ChatGPT/Gemini等）の生データが集約されます。
これから指定するキーワードや特定のトピックについて、最新情報を調査し、既存の知識と紐付けて整理してください。

### 指示
1. **検索と抽出**:
   ブラウザを使い、指定された「{{キーワードまたはトピック}}」に関する最新情報を探してください。
   - 論文の場合は、提案手法の独自性、実装（GitHub）の有無、将来の課題を抽出。
   - 市場動向の場合は、主要企業の動き、市場規模、技術的なボトルネックを抽出。

2. **Obsidianへの保存**:
   - 論文の場合: `knowledge/inbox/academic_papers/` 配下に「YYYY_タイトル（短縮）.md」として保存。
   - 市場動向・技術調査の場合: `knowledge/inbox/webclips/` または `knowledge/research/` 配下の適切なサブフォルダに保存。

3. **知識の紐付けと統合**:
   - `knowledge/research/tech_notes/` や `knowledge/research/mlops/` 等にある既存のメモを検索し、関連がある場合はリンク（`[[Note Name]]`）を貼ってください。
   - 新しい知見が既存のトレンドとどう関わるか、簡単な考察を加えてください。

### 制約事項
- `knowledge/` 配下のディレクトリ構造を厳守してください。
- 重複するファイルを作成しないでください。
- 日本語と英語の両方のリソースを対象にしてください。

---

## 実行例
> 「ロボティクスにおけるVLA（Vision-Language-Action）モデルの最新トレンドを調べて、research/roboticsにまとめて。既存のPhysical AIに関するメモとも紐付けて。」
